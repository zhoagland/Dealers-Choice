# Playtest round 1 (2026-11-14)

Feedback from the first multi-person playtest, sorted by area. Status: `[ ]` open, `[x]` done.

## Table look and feel
- [ ] P1-1 Spread the UI out to use the whole screen; less serious, a bit more arcade-like.
- [ ] P1-2 Desktop first: mobile support is lower priority, so desktop gets the space.
- [ ] P1-3 An oval "table" with players' Discord profile pictures around it (like Poker Party).
- [ ] P1-4 Card animations while dealing: cards fly out of a deck (like Poker Party).
- [ ] P1-5 Showdown screen: everyone sees the winning hand without opening the replay.
- [ ] P1-6 Rules for the current game shown on the right for reference.
- [ ] P1-7 Remove/explain the debug-looking text above the community cards (phase/notes line).
- [ ] P1-8 Check capitalization of words across the UI.
- [ ] P1-9 Four-color deck option (also inside Discord).
- [ ] P1-10 Mama's Favorite: space between pairs.

## Sound
- [ ] P1-11 Background sound, can be turned off.
- [ ] P1-12 Turn notification sound, can be turned off.

## Actions
- [ ] P1-13 Raise picker: slider or up/down buttons from 50¢ to $2 in 50¢ steps, not just min/max.
- [ ] P1-14 Hit / Stand (and other actions) read as real labels, not "choose 0 / choose 1".
- [ ] P1-15 Discard / group / choose cards by clicking the cards.
- [ ] P1-16 Order cards by dragging them (like Balatro); reorder your hand any time.

## Flow
- [ ] P1-17 Declares (in/out, high/low), pair grouping and discards happen at the same time.
- [ ] P1-18 Pass the Trash passes/orders at the same time.
- [ ] P1-19 Late joiners and players sitting out still see the game and community cards (not hole cards).
- [ ] P1-20 A pause between games so players can join.

## Game rules
- [ ] P1-21 Scare-a-moosh: the first to name the game is left of the dealer; the dealer moves each
      hand until the declarer wins; the next game's dealer is left of that declarer.
- [ ] P1-22 Indian games: show cards when folded.
- [ ] P1-23 7/27: the betting order rotates after each hit round.
- [ ] P1-24 Whooh Ray: the player left of the dealer leads the first trick.
- [ ] P1-25 Whooh Ray: show the cards played this trick in front of each player.
- [ ] P1-26 Whooh Ray: show each player's trick count.
